Laravel Project Deployment on AWS

Project Overview & Deployment Scope

Deploying dynamic PHP/Laravel applications into high-reliability cloud environments requires careful handling of web server virtualization, database connection security, automated dependency installation, and zero-downtime release workflows. This project establishes a streamlined, reproducible deployment architecture for Laravel on Amazon Web Services (AWS).

Infrastructure as Code with Terraform

Rather than manually configuring cloud resources through the AWS web console, the entire target hosting environment was scripted with reusable Terraform manifests:

  • Virtual Private Cloud (VPC): Dedicated public subnets with internet gateway routing and DNS hostnames enabled.
  • Security Groups: Strict perimeter security isolating SSH access (port 22) to designated administrator IP blocks, while routing HTTP (port 80) and HTTPS (port 443) traffic through SSL certificates.
  • Amazon EC2 Instance: Compute instance provisioned with Amazon Linux, configured with user-data bootstrap scripts to install Apache HTTP Server, PHP runtime, Composer, and MySQL dependencies automatically on first boot.

Automated CI/CD Delivery with GitHub Actions

A declarative GitHub Actions workflow triggers on every push to the main branch, eliminating manual server logins and ensuring continuous deployment integrity:

  • Automated Testing: Runs code quality linters and PHPUnit test suites before initiating the server deployment stage.
  • Secure Deployment via SSH: Authenticates securely to the EC2 instance using GitHub repository secrets and encrypted SSH private keys.
  • Atomic Release Management: Deploys releases into timestamped directories and switches a symbolic link to the current build, allowing instant zero-downtime rollbacks if errors occur.
  • Laravel Optimization: Automates Composer package installation, runs database migrations safely, and executes php artisan config:cache, route:cache, and view:cache for production speed.
Reliability Highlight: Atomic symlink deployments guarantee that users never experience broken page renders or missing assets while files are being uploaded to the server during updates.

Security & Web Server Hardening

The Apache web server was configured with strict security headers (X-Frame-Options, Content-Security-Policy), disabled directory indexing, optimized OPcache settings for rapid PHP execution, and Let's Encrypt automated SSL certificate renewal.
