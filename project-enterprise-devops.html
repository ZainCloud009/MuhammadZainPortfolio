Project Overview & Architectural Goals

Enterprise applications demand high availability, reproducible environments, and secure delivery cycles. This project implements a full production architecture on AWS designed to eliminate deployment bottlenecks and infrastructure drift by combining modular Infrastructure as Code (IaC) with automated Jenkins delivery pipelines.

Modular Infrastructure as Code with Terraform

All AWS resources are defined declaratively across isolated Terraform modules, enabling consistent recreation across staging and production environments:

  • Network Layer: Custom multi-tier VPC featuring public subnets across two Availability Zones for redundant Application Load Balancers, and private subnets isolating compute instances and databases.
  • Compute & Scaling: Auto Scaling Groups (ASG) of Amazon EC2 instances running hardened Linux images behind an AWS Application Load Balancer (ALB).
  • Database Layer: Amazon RDS MySQL configured with Multi-AZ automated failover, private subnet placement, and automated backup windows.
  • State Management: Remote Terraform state stored in Amazon S3 with server-side AES-256 encryption and state locking powered by Amazon DynamoDB to prevent concurrent pipeline conflicts.
IaC Best Practice: Strict least-privilege AWS IAM roles were provisioned so EC2 compute instances interact with S3 buckets and CloudWatch monitoring without embedding static credentials anywhere in code.

Automated CI/CD Pipeline with Jenkins & Docker

The continuous integration and delivery workflow is orchestrated through a Jenkins Declarative Pipeline triggered automatically on GitHub commits:

  • Build Stage: Applications are containerized into lightweight Docker images, ensuring environmental parity between developer machines and production.
  • Test & Quality Gates: Automated unit test execution and static code linting occur prior to image promotion.
  • Zero-Downtime Deployment: Rolling deployments update target group instances behind the ALB, draining active connections smoothly without user interruption.
  • Automated Rollback: If target group health checks fail post-deployment, the pipeline automatically halts and rolls back traffic to the previous healthy container image.

Disaster Recovery & S3 Synchronization

Scheduled Bash scripts and cron automation synchronize database dumps and application log archives to an offsite S3 bucket with strict lifecycle transition rules to Glacier for low-cost compliance storage.
